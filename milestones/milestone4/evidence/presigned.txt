Presigned flows: the photo goes from curl straight to the store (port 9000), and is fetched back from the store by curl, not through the API (port 8000).

API=http://localhost:8000/api/v1
ADMIN='X-Admin-Token: dev-admin-token'
JSON='Content-Type: application/json'

$ curl -s -X POST $API/items -H "$JSON" -d '{"name":"Blue umbrella","type":1,"location_id":1,"user_id":1}' -w "$CODE"
{"name":"Blue umbrella","description":null,"location_id":1,"user_id":1,"id":1,"type":1,"status":"open","created_at":"2026-10-05T16:26:36.708933Z","photo_url":null}
HTTP 201

# 1. The API issues a presigned PUT. Note the bytes: this call sends nothing up.
$ curl -s -o $TMP/upload.json -X POST $API/items/1/images -w 'HTTP %{http_code}: %{size_upload} bytes sent to the API, %{size_download} bytes of JSON back\n'; jq . $TMP/upload.json

# 2. curl uploads the photo directly to the store.
$ curl -s -X PUT --upload-file $TMP/photo.jpg "$UPLOAD_URL" -w 'HTTP %{http_code}: %{size_upload} bytes sent to %{remote_ip}:%{remote_port}\n'
HTTP 200: 8229 bytes sent to ::1:9000

# 3. The completion callback. Again nothing is sent up.
$ curl -s -X POST $API/items/1/images/$UPLOAD_ID/complete -w '\nHTTP %{http_code}: %{size_upload} bytes sent to the API\n'
